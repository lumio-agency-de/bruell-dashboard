# Bad-Dashboard · Brüll GmbH (Vorschau)

Arbeits-Dashboard für den Badbau: 13 Level von der Anfrage bis zum Abschluss,
digitale Formulare, Projektordner, Kunden-Upload-Link, Ebenen (Geschäftsführung,
Planung, Monteur, Partner) und Unternehmens-Kennzahlen.

**Ausprobieren:** die GitHub-Pages-Seite mit `?demo=1` öffnen — dann sind Beispielprojekte geladen.
Links unten über „Ansicht als“ zwischen den Ebenen wechseln.

Die Vorschau läuft im lokalen Modus: Eingaben bleiben nur im eigenen Browser.
Bedienung: `ANLEITUNG.md` · Cloud-Betrieb: `supabase/ANLEITUNG-CLOUD.md`
