Brüll Dashboard

Als App einrichten

Mit eigenem Symbol auf dem Schreibtisch, im Dock bzw. in der Taskleiste – das Dashboard öffnet sich dann in einem eigenen Fenster wie ein Programm.

Vorher einmal je Gerät: Das Gerät muss im Netz des Brüll-Servers sein und dem Server-Zertifikat vertrauen (sonst warnt der Browser). Mac: Ordner „Brüll Server/einrichten/Gerät verbinden (Mac)“ · Windows und iPad: bekommt ihr von Miko.

Adresse des Dashboards:

Windows-PCMicrosoft Edge oder Google ChromeDein Gerät
  1. Das Dashboard in Microsoft Edge öffnen und anmelden.
  2. Oben rechts auf ⋯ → Apps → „Diese Website als App installieren“ (bzw. „Brüll installieren“).
  3. Im nächsten Fenster „Desktopverknüpfung erstellen“ und auf Wunsch „An Taskleiste anheften“ anhaken → Zulassen.

In Chrome: ⋮ → Streamen, speichern und teilen → „Seite als App installieren“. Das Symbol liegt danach auf dem Desktop und im Startmenü.

MacSafariDein Gerät
  1. Das Dashboard in Safari öffnen und anmelden.
  2. In der Menüleiste Ablage → „Zum Dock hinzufügen …“ → Name „Brüll“ lassen → Hinzufügen.
  3. Für den Schreibtisch: Im Finder Programme öffnen (bzw. „Programme“ im Benutzerordner), das Symbol „Brüll“ mit gedrückter ⌘+⌥ auf den Schreibtisch ziehen (legt einen Verweis an).

Einfacher Lesezeichen-Weg: Die Adresse oben in Safari mit der Maus auf den Schreibtisch ziehen – öffnet das Dashboard dann im normalen Safari-Fenster.

iPad / iPhoneSafariDein Gerät
  1. Das Dashboard in Safari öffnen und anmelden.
  2. Auf Teilen ⬆︎ tippen → „Zum Home-Bildschirm“ → Hinzufügen.
  3. Das Symbol „Brüll“ liegt jetzt auf dem Home-Bildschirm und öffnet das Dashboard ohne Safari-Leisten.
AndroidChromeDein Gerät
  1. Das Dashboard in Chrome öffnen und anmelden.
  2. ⋮ → „App installieren“ bzw. „Zum Startbildschirm hinzufügen“.

Die App ist dasselbe Dashboard wie im Browser – gleiche Anmeldung, gleiche Daten. Ist der Brüll-Server aus oder das Gerät nicht im Firmennetz, öffnet sie sich ohne Inhalt.
