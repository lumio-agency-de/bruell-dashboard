# Heizungs-Dashboard · Brüll GmbH (Vorschau)

Arbeits-Dashboard für die Heizungserneuerung: 11 Level von der Anfrage bis zum Abschluss,
digitale Formulare (Bestandsaufnahme, Erstgespräch, GEG-Beratung, Baustellenbesichtigung,
Tankdemontage, TAF, Gasprüfung, Restarbeiten, Einweisung), Förderung (KfW BZA/BZD),
Projektordner, Kunden-Upload-Link, Ebenen (Geschäftsführung, Planung, Monteur, Partner)
und Unternehmens-Kennzahlen. Gegenstück zum Bad-Dashboard – gleiche Technik und Optik.

**Ausprobieren:** die GitHub-Pages-Seite mit `?demo=1` öffnen — dann sind Beispielprojekte
und Demo-Zugänge geladen (Passwort `demo1234`).

Die Vorschau läuft im lokalen Modus: Eingaben bleiben nur im eigenen Browser.
